== Dependencies

This extension is written against the OpenCL Specification v3.0.19.

This extension requires OpenCL 3.0.

== Overview

This extension gives applications explicit control over some aspects of memory
management. It can be used for performance tuning or debugging.

- {CL_DEVICE_MEMORY_CONTROLS_LOCAL_MEMORY_ARM} is set when the device supports

(Modify Section 5.2.1, *Creating Buffer Objects* and Section 5.3.1, *Creating Image Objects* ) ::
+
--

(Add the following to Table 18, _List of supported buffer creation properties_ and Table 22, _List of supported image creation properties_) ::
+
--
[cols="1,1,4",options="header"]
|====
| Property
| Property Value
| Description

| {CL_MEM_COHERENCY_ARM}
| {cl_mem_coherency_flags_arm_TYPE}
| Override the coherency settings selected by the implementation.
 +
- {CL_MEM_COHERENCY_INNER_SHAREABLE_ARM}, when set, enables inner shareability
  for the memory that backs the memory object. If it is not set, then inner
  shareability is disabled. Inner shareability is always supported. +
- {CL_MEM_COHERENCY_OUTER_SHAREABLE_ARM}, when set, enables outer shareability
  for the memory that backs the memory object. If it is not set, then outer
  shareability is disabled. If it is set and one or more devices do not support
  outer shareability then memory object creation will fail. If it is set then
  {CL_MEM_COHERENCY_INNER_SHAREABLE_ARM} must be set. +
|====

(Add the following to Table 31, _List of param_values accepted by *clSetKernelExecInfo*_) ::

[cols="1,1,4",options="header"]
|====
| cl_kernel_exec_info
| Type
| Description

| {CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_BACKING_ARM}
| {cl_kernel_exec_info_local_memory_backing_arm_TYPE}
| Selects the backing for local memory. Valid values are: +
 +
- {CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_BACKING_GLOBAL_ARM} specifies that local
  memory is backed with global memory. +
- {CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_BACKING_COMPUTE_UNIT_ARM} specifies that
  local memory is backed by memory wihin the compute unit. +
- {CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_BACKING_AUTO_ARM} specifies that the
  implementation selects the backing for local memory. +

| {CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_HASHING_ARM}
| {cl_bool_TYPE}
| Enables or disables address hashing when local memory is backed within the
  compute unit ({CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_BACKING_COMPUTE_UNIT_ARM}
  or {CL_KERNEL_EXEC_INFO_LOCAL_MEMORY_BACKING_AUTO_ARM}). This control
  has no effect otherwise. +
 +
- {CL_FALSE} specifies that address hashing is disabled. +
- {CL_TRUE} specifies that address hashing is enabled. +

|====
